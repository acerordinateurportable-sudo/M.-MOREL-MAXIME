# 📚 Pronote - Grand Paris

Site de gestion scolaire pour l'établissement RP Discord "Grand Paris", inspiré de la plateforme Pronote.

## 🎯 Fonctionnalités

- ✅ **Système de connexion** - Authentification sécurisée
- ✅ **Tableau de bord** - Vue d'ensemble des informations importantes
- ✅ **Gestion des notes** - Consultation des notes et moyenne générale
- ✅ **Devoirs** - Suivi des devoirs par classe
- ✅ **Emploi du temps** - Horaires des cours
- ✅ **Absences** - Suivi des absences et justificatifs
- ✅ **Annonces** - Informations de l'établissement
- 🔄 **Messagerie** - En développement

## 🚀 Installation

### Prérequis
- Node.js (v14+)
- npm

### Étapes

1. Cloner le repository
```bash
git clone https://github.com/acerordinateurportable-sudo/M.-MOREL-MAXIME.git
cd M.-MOREL-MAXIME
```

2. Installer les dépendances
```bash
npm install
```

3. Démarrer le serveur
```bash
npm start
```

4. Ouvrir le navigateur
```
http://localhost:3001
```
